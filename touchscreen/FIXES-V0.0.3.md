# V0.0.3

Includes the V0.0.2 scrolling, RGB synchronization, and pairing fixes. Also clears references to deleted Setup widgets when the Remove pairing confirmation opens, so a pending Wi-Fi scan or scale discovery cannot update freed UI objects.
