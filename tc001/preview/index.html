Connect to the scale over Wi-Fi
  1. Flash the TC001 through USB when it arrives.
  2. Join the clock’s KegPixel setup Wi-Fi and open 192.168.4.1 to configure home Wi-Fi and the scale address.
  3. On the scale webpage select Wi-Fi touchscreen → Add touchscreen and enter the six-character code shown on the clock.
  4. The clock remembers its key and receives encrypted readings over Wi-Fi. No Home Assistant or MQTT broker is needed. Each scale supports one Wi-Fi display.
