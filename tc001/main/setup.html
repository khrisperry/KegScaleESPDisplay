This is an approximate charge estimate, not a fuel gauge or runtime estimate. Hardware revisions and charging can affect it. The clock also has a battery page, accessible with left/right even if MQTT is offline.

Battery calibration (optional)

Default raw ADC endpoints are 565 empty and 656 full, a mapping reported for newer TC001 boards. If the estimate is wrong, use observed empty/full raw readings from this same firmware. Do not deliberately run the battery flat just to calibrate it.

MQTT broker

Use the broker address from the scale's Home Assistant settings. Enter only an IP or hostname, without mqtt:// or a port.

TLS requires a broker certificate trusted by the built-in public certificate authorities, a matching hostname, and Internet time synchronization. Self-signed/private CA certificates are not supported in this version. Standard local MQTT uses port 1883 with TLS off.

Leave username and password blank only if your broker allows anonymous access. A blank password keeps the saved one for the same broker and username.

Scale to display

Copy the Base topic from the scale's Home Assistant settings. It uses all six final MAC digits, which may differ from the four digits in the scale's name. Example only: kegscale/abcdef. Do not enter a Home Assistant entity ID, wildcard, or trailing /state.

The clock reads <base topic>/state and <base topic>/availability. It never sends commands to the scale.

After restarting, allow up to 10–20 seconds for a fresh scale reading. NO DATA means no fresh reading, a scale offline notice, or more than 35 seconds without a valid update. MQTT WAIT means the broker connection is unavailable. Hold the middle button for 5 seconds to reopen setup.
