Authorize on the scale
  1. Save Wi-Fi and the scale address here.
  2. Reconnect your phone to your usual Wi-Fi.
  3. On the scale, open Settings → Displays → Wi-Fi touchscreen → Add touchscreen.
  4. Enter the six-character code shown on this clock. It may include letters A–F.

The TC001 uses the same encrypted connection as the Wi-Fi touchscreen. Each scale currently supports one Wi-Fi display, alongside its separate BLE e-paper display.
